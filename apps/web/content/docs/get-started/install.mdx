---
title: Install
description: Install Devo online, from source, or in an offline environment.
---

Devo v0.2.0 installs as a complete user-local application: the Rust backend,
compiled TUI, private Node.js 24 and Python 3.13, locked dependencies, and `rg`.
System Node.js, Python, npm, pip, Bun and Rust are not required. Keep the complete
installation directory together; copying only the Rust executable is insufficient.
Desktop packages also include the private Python runtime. Linux requires glibc
2.28+; the archive's `musl` suffix describes only the Rust backend.

## Linux And macOS

Run the online installer:

```bash
curl -fsSL https://raw.githubusercontent.com/7df-lab/devo/main/install.sh | sh
```

Install a specific release:

```bash
curl -fsSL https://raw.githubusercontent.com/7df-lab/devo/main/install.sh | sh -s -- --version v0.2.0
```

The Unix installer accepts these options:

| Option | Use when |
| --- | --- |
| `--version <version>` | Pin the Devo release instead of installing the latest release. |
| `--binary <path>` | Install a local `devo` binary instead of downloading a release archive. |
| `--install-dir <dir>` | Install into a custom directory. |
| `--offline` | Install from files placed next to `install.sh`. |
| `--no-modify-path` | Skip shell profile updates. |

Useful environment variables:

| Variable | Effect |
| --- | --- |
| `VERSION` | Same as `--version`. |
| `DEVO_INSTALL_DIR` | Same as `--install-dir`. |
| `DEVO_SKIP_RG_INSTALL=1` | Skip a separate legacy `rg` download; full bundles already include it. |

## Windows

Run the online installer in PowerShell:

```powershell
irm 'https://raw.githubusercontent.com/7df-lab/devo/main/install.ps1' | iex
```

Install a specific release:

```powershell
$env:VERSION = "v0.2.0"; irm 'https://raw.githubusercontent.com/7df-lab/devo/main/install.ps1' | iex
```

The Windows installer installs to the current user's local program directory
and updates the user `Path`. It does not require an administrator shell.

## Build From Source

Use this path when you are contributing to Devo or testing unreleased changes:

```bash
git clone https://github.com/7df-lab/devo.git
cd devo
cargo build --release
./target/release/devo --version
```

On Linux and macOS, you can install that local binary with the installer:

```bash
./install.sh --binary ./target/release/devo
```

## Upgrade

Upgrade an existing online installation:

```bash
devo upgrade
```

On Linux and macOS, `devo upgrade` downloads `install.sh` and runs it. On
Windows, it starts a detached PowerShell installer because Windows cannot
replace the running `devo.exe` while the current process still owns the file.

## Install Without Internet Access

Download the complete CLI archive for the destination OS/architecture and
`SHA256SUMS.txt` from the same release on a connected computer. Verify its SHA-256
and transfer the files. Extract the full archive and run its `devo` executable
directly, or run the included installer from the extracted directory:

```bash
sh ./install.sh --offline
```

```powershell
.\install.ps1 -Offline
```

The archive includes ripgrep and all TUI/Python dependencies. First launch does
not download runtimes or run package managers. Re-running the installer repairs
the original incomplete v0.2.0 installation. Close running Devo instances before
upgrading on Windows. Provider settings and sessions stay in your Devo home.

Cloud models still require connectivity. Offline inference requires a compatible
local endpoint with model weights already downloaded, or an accessible LAN
before disconnecting. Disable catalog/update refreshes in `config.toml`:

```toml
[updates]
enabled = false
check_on_startup = false

[catalog]
offline = true
refresh_on_startup = false
```

These flags do not block provider, tool or MCP traffic. Use `devo doctor` to check
the private runtimes and Python dependencies.

## Verify

Open a new terminal and run:

```bash
devo --version
devo doctor
```

If `devo` is not found, add the install directory to `PATH` and reopen the
terminal. If repository search fails with an `rg` error, rerun the installer or
install `rg` next to the `devo` binary.
